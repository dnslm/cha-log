# Источник данных

Файл `teas.csv` создан на основе [Chinese Tea Dataset](https://chinatea.house/dataset/) (China Tea House).

Условия автора: бесплатное использование для образовательных и некоммерческих целей, ссылка на источник приветствуется. Эти условия действуют и на изменённую версию файла.

## Что изменено

- добавлены русские переводы названий, категорий и регионов.

Исходный файл: https://chinatea.house/data/chinese-tea-dataset.csv
